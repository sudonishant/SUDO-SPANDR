RFC Header Protocol Authentication Matrix

SPF (Sender Policy Framework)
Verifies if sending server IP is authorized in DNS SPF TXT record (प्रेषक आईपी प्राधिकरण जांच)
DKIM (DomainKeys Identified Mail)
Cryptographic RSA signature proving email body & headers were not tampered in transit (डिजिटल हस्ताक्षर सुरक्षा)
DMARC (Domain-based Policy)
Enforces organizational policy against unauthorized spoofing (डोमेन अलाइनमेंट एवं सुरक्षा नीति)
🔍 What "BEST EFFORT" Actually Evaluated (बेस्ट एफर्ट में क्या जांचा गया):
1. Public DNS Policy Check: Sender domain lacked a published strict enforcement policy (p=reject / p=quarantine) in public DNS records.
2. SPF Pass Fallback: Checked connecting MTA against envelope authorization to prevent false rejections.
3. Return-Path Alignment: Verified that envelope bounce domain matches the visible From: domain.
4. Cryptographic DKIM Header: Inspected message headers for DKIM selector integrity.
👉 सार (Hindi): जब किसी डोमेन के डीएनएस में सख्त 'p=reject' पॉलिसी नहीं होती, तब सिस्टम झूठे अलर्ट से बचने के लिए एसपीएफ, रिटर्न-पाथ और डीकिम के आंतरिक मिलान द्वारा बेस्ट-एफर्ट सत्यापन करता है।
